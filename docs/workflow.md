# OKR 系統操作流程（管理者與同仁）

## A. 管理者流程

1. 登入系統。
2. 選擇年度（2026 起，未來年度可持續新增）。
3. 選擇部門/課別/同仁。
4. 建立該同仁年度 OKR（O1~O5，可少於 5）。
5. 每個 O 建立 2~5 個 KR、設定 target 與權重。
6. 年中檢核：更新數值、檢視達標率、填寫主管 comment。
7. 年底檢核：完成最終評分與改善建議。

## B. 同仁流程

1. 登入後僅看自己的 OKR。
2. 持續更新 KR 當前值（current value）。
3. 年中檢核填寫 self comment。
4. 年底檢核填寫年度總結 comment。

## C. 統計邏輯

- 個人：加權總分。
- 課別：課內同仁加權總分平均。
- 部門：部門內課別平均。
- 全公司：全部門平均。

## D. 建議報表

- 年中達標率報表（個人/課/部門）。
- 年底達標率報表（個人/課/部門）。
- 未達標 KR 清單（含責任人、改善期限）。
