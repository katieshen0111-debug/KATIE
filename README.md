# Taiwan Boiler Sales Analysis (2026)

This repository contains an estimate-based analysis for Taiwan boiler sales by three categories:

- Once-through boiler (貫流式鍋爐)
- Fire-tube steam boiler (煙管式蒸汽鍋爐)
- Water-tube steam boiler (水管式蒸汽鍋爐)

## Files

- `report/taiwan_boiler_market_analysis_2026.md`: Full Chinese report and forecast for 2027-2028.
- `data/boiler_sales_estimate_tw_2022_2028.csv`: Structured dataset used in charts.
- `charts/boiler_sales_chart.md`: Mermaid charts for GitHub rendering.

## Note

The analysis is **estimate-based**, built from public information and explicit assumptions because no single official open dataset publishes complete annual sales volumes by these exact three boiler types in Taiwan.
