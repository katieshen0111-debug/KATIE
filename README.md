# 全公司 OKR 追蹤系統（2026+）

這個專案提供一個可直接落地的 **OKR 管理系統規格 + 資料庫結構 + 範例資料 + 計算邏輯**，支援：

- 依組織圖管理（總經理 → 部門 → 課別 → 同仁）。
- 各級主管登入後，為不同同仁設定每年度 OKR（O1～O5，可少於 5 個）。
- 從 **2026 年**開始，持續追蹤至 2027、2028、2029、2030...（不限年份）。
- 每年可在 **年中（Mid-Year）**、**年底（End-Year）**進行達標檢核。
- 每位同仁可在檢核點填寫自評註解（comments）。
- 只要有歷史資料，新年度可「帶入」前一年 OKR 再調整。

---

## 1. 系統角色與權限（RBAC）

| 角色 | 權限 |
|---|---|
| General Manager（總經理） | 檢視全公司、核准各部門 OKR、檢視年度統計 |
| Department Manager（部門主管） | 管理部門內課別/同仁 OKR、年中/年底評核 |
| Section Leader（課長） | 管理課別內同仁 OKR、追蹤 KR 進度 |
| Employee（同仁） | 維護自我 KR 進度、填寫年中/年底 comments |
| HR/Admin（管理部） | 帳號、組織、權限、模板管理 |

> 建議：主管可跨層查看（向下可見），同仁僅可看到自己。

## 3. OKR 結構標準

### Objective（O）
- 每位同仁每年度可有 O1～O5（可少於 5 個）。
- 每個 Objective 必須：
  - 對應年度（例如 2026）
  - 對應職能（銷售、設計、生產、財務等）
  - 設定權重（建議總和 100%）

### Key Results（KR）
- 每個 Objective 建議 2～5 個 KR。
- KR 必須可量化（例如：營收成長率、良率、交期達成率）。
- KR 欄位建議：
  - 指標名稱
  - 基準值 baseline
  - 目標值 target
  - 當前值 current
  - 計分方式（越高越好／越低越好／區間）

### 評分建議
- KR 達成率 = `current / target`（越高越好時）
- Objective 分數 = 該 O 下 KR 平均達成率
- 年度總分 = 各 Objective 分數 × 權重加總
- 達標門檻（可調）：
  - ≥ 70%：達標
  - 50%～69%：部分達標
  - < 50%：未達標

## 4. 年度流程（2026 起）

1. **年度初始化（每年 1 月）**
   - 建立年度（2026、2027...）
   - 可從前一年複製 OKR 作為草稿
2. **主管設定 OKR（Q1）**
   - 主管為同仁設定 O1～O5
   - 同仁可補充執行計畫
3. **年中檢核（Mid-Year）**
   - 更新 KR 目前值
   - 主管評估 + 同仁 comments
4. **年底檢核（End-Year）**
   - 最終達標率統計（個人/課別/部門/全公司）
   - 留存 comments 與改善事項
5. **跨年帶入**
   - 將可延續目標自動帶入下一年度（可編輯）

---

## 5. KPI/統計看板（核心）

- 個人達標率（年中、年底）
- 課別平均達標率
- 部門平均達標率
- 職能別達標率（Sales/Design/QC...）
- 目標型態達標率（成長型、品質型、效率型）
- 未達標 Top N KR 清單

## 7. 最小可行版本（MVP）建議功能

- 組織架構維護。
- 年度 OKR 建立（O1～O5，可少於 5）。
- KR 進度更新。
- 年中/年底檢核 + comments。
- 年度達標率統計。
- 前一年資料帶入下一年。
